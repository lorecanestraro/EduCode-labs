# Laboratórios EduCode

Cadernos do Google Colab usados nos laboratórios da trilha **Python** do app EduCode,
uma formação em Computação para professores da educação básica.

Cada caderno tem o desafio, um aquecimento com exemplos prontos, a célula para você
completar e uma conferência automática que mostra o **código de conclusão**. Digite
esse código no app para concluir o laboratório.
